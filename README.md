# SELFIE Dental AI — AI-Assisted Oral Health Screening

## Overview

SELFIE Dental AI is a capstone project exploring how artificial intelligence and patient-reported information can support preliminary oral health screening. The system combines patient questionnaires with computer vision-based image analysis to help assess potential oral health concerns.

The project integrates image-based analysis, patient input, and backend processing into a unified workflow, with an emphasis on image quality, interpretability, and usability.

## Key Features

* **Multimodal Screening:** Combines patient questionnaire responses with computer vision-based image analysis.
* **Image Quality Assessment:** Incorporates image quality checks to identify unsuitable photographs before downstream analysis.
* **Explainable AI:** Uses Grad-CAM to help visualize image regions that contribute to model predictions.
* **Backend Integration:** Connects questionnaire data and image analysis through backend architecture.
* **User-Centred Design:** Considers usability, data quality, and clinical workflow requirements.
